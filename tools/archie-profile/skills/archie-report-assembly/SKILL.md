# Archie Report Assembly

Use this only after a public evidence job is complete and the relevant
official-source chunks have been retrieved from `archie_knowledge`.

## Report order

1. **What a visitor can currently see** — short plain-English summary.
2. **Scope** — pages, media items and collection date.
3. **Evidence-led findings** — found / not found within scope / needs owner
   confirmation / not applicable, with page URL and evidence reference.
4. **Prioritised repairs** — practical, smallest useful changes.
5. **Developer handover** — implementation notes only where evidence supports
   one.
6. **Human review questions** — ownership, editorial control, AI-system use
   and assets a public crawl cannot establish.

Use the grounded-citations skill for regulation/guidance claims. Do not create a
compliance certificate, guarantee, legal opinion or a single percentage score
that hides the evidential uncertainty.
